AR 双手手势交互特效 使用说明
================================

一、运行方法
1. 双击“双击启动AR.bat”。
2. 脚本会自动启动本地 HTTP 服务（自动选择 8000-8999 中未被占用的端口），
   并自动打开 Chrome 或默认浏览器。
3. 页面打开后点击“启动摄像头”，首次使用需要允许浏览器访问摄像头。
4. 将双手同时放入画面并伸开手指，双手之间会出现红、蓝、绿三块连续滤镜面片。

二、控制说明
- 启动摄像头：开启摄像头和 MediaPipe 实时手势识别。
- 演示模式：不需要摄像头，自动生成双手和三块面片，用于检查滤镜效果。
- 重置：停止摄像头或演示，回到初始状态。
- 跟手平滑度：拖动滑块可调整关键点插值平滑程度，越靠右越平滑。
- 摄像头启动后控制栏会自动弱化，鼠标移到下方控制栏会重新显示。

三、文件结构
- index.html：页面入口。
- src/styles.css：界面样式。
- src/app.js：手势识别、坐标映射、三块滤镜渲染逻辑。
- vendor/mediapipe/tasks-vision/：MediaPipe Tasks 运行库与 WASM 文件。
- vendor/mediapipe/models/：手部关键点和人物分割模型文件。
- Start-LocalServer.ps1：本地 HTTP 服务脚本。
- 双击启动AR.bat：一键启动入口。
- 使用说明.txt：本说明文件。

四、注意事项
1. 必须通过 http://localhost 打开页面，不能直接用 file:// 打开，
   否则浏览器会禁止调用摄像头。
2. MediaPipe 手势识别、人物分割所需的运行库、WASM 和模型文件已内置在项目的
   vendor/mediapipe 目录中，加载模型不需要联网。
3. 建议使用最新版 Chrome 或 Edge 浏览器。
4. 关闭服务：关闭命令行窗口，或在服务窗口中按任意键。

五、常见问题
- 摄像头权限被拒绝：在浏览器地址栏重新允许摄像头权限后重试。
- 未找到摄像头：检查摄像头连接和驱动，确认设备未被禁用。
- 摄像头被占用：关闭正在使用摄像头的其他软件后重试。
- MediaPipe 模型加载失败：确认 vendor/mediapipe/tasks-vision 和
  vendor/mediapipe/models 目录完整存在，不要重命名或删除这些目录。
- 只识别到一只手：页面顶部会提示，请将双手同时放入画面，并保持手部光照充足。
